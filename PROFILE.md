# NutrientsDB

A downloadable global food-composition dataset (~2.9M foods, 86 normalized nutrient fields, 180+ countries) sold under a one-time license, fronted by a free, keyless, read-only public Sample API exposing a 1,000-food sample with the full nutrient schema.

- **Provider:** https://www.nutrientsdb.com/
- **Documentation:** https://www.nutrientsdb.com/api/docs
- **Base URL:** https://www.nutrientsdb.com/api
- **Tags:** nutrition, food, nutrients, food-composition, data, search, sample-data, dataset, ai-builders
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** no
- **Confidence:** 80/100

## APIs

- **NutrientsDB Sample API** — Free, keyless, read-only REST API providing access to the public 1,000-food sample with the full 86-field normalized nutrient schema. Supports search by name and lookup by public ID. (`https://www.nutrientsdb.com/api`)

> Public keyless read-only Sample REST API confirmed via a live public Postman collection. A declared OpenAPI contract at https://www.nutrientsdb.com/api/openapi and docs at /api/docs were blocked to the fetcher (url_not_allowed) so their contents are unverified and not cataloged as reachable.
